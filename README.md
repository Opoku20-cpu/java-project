# Student Grading System
This project is designed to calculate students' grades using java

#Technologies Used
It uses java features like String class, int data and scanner class to collect and process student information.
The program prompts students to enter their names , ID ,courses, and examination scores.

It uses conditional statements(if, else if and else) to evaluate examination scores and assign the appropriate grades. It also checks whether the scores are within the valid range.



## HOW TO RUN THE PROGRAM
1: Install Java Development Kit (JDK) on your computer.
2: Open the project using IntelliJ IDEA.
Locate the assessment.java file.
Click the green Run button beside the main method.
Enter the student's name, ID, course and Examination score when prompted.
The program will calculate and display the student's grade.
